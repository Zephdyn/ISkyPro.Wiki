# 2.1.0-preview.3

发布日期：2026-09-19

本预览版聚焦 OneBot 接入体验：修复开启鉴权的协议端无法连接的问题，新增一键本机探测与连接测试，并让设置页能够切换平台、正确退出当前平台账号。

## 🐛 修复

- OneBot 连接：修复协议端（NapCat / LLOneBot 等）开启 `access_token` 后正向 WebSocket 始终无法连接的问题——握手现在会携带标准的 `Authorization: Bearer` 头，并同时附加 `access_token` 查询参数以兼容只读取 query 的实现。
- OneBot 诊断：连接失败不再只提示 `Unable to connect to the remote server`，而是给出可操作原因：鉴权失败、端点不存在（端口填错）、连接被拒绝、主机无法解析、超时等。
- OneBot 地址：填写 `127.0.0.1:3001` 这类缺少 `ws://` 的地址、末尾多余的 `/` 都会被自动规范化；同一份配置的地址非法时只提示一次并按退避重试，不再每几秒刷一条日志。
- OneBot 发送：HTTP API 发送补齐标准鉴权头，并兼容 OneBot v12 的字符串型 id（`"10001"`）。
- OneBot 反向 WebSocket：修复选择反向模式保存后进不去主界面的问题。反向模式由协议端主动连接 ISkyPro，因此机器人 QQ 号不再必填——协议端连上后会从事件中自动识别并保存，仪表盘与日志随即按该账号归属；表单会给出可直接粘贴的接入地址。
- OneBot 连接模式：连接模式下拉不再提供纯 HTTP。该模式当前只能调用 API、无法接收消息事件，选中后会出现“已启用但收不到消息”的困惑；现在保存时会被拒绝并提示改用正向/反向 WebSocket。

## ✨ 新功能

- 连接测试：OneBot 登录页与设置页新增“测试连接”。点击后会用当前填写的内容实际握手并调用 `get_login_info`，成功后自动回填机器人 QQ（self_id）、昵称与协议版本，失败时直接列出排查建议。
- 本机自动探测：新增“自动探测（本机）”，扫描常见协议端端口（NapCat 3001 / 3000、go-cqhttp 6700 等）；探测到候选后一键应用推荐配置。仅探测本机回环地址，不会扫描其他主机。
- 快速配置：新增“NapCat 预设”，一键填入 `ws://127.0.0.1:3001` 与 `http://127.0.0.1:3000`；重连延迟、退避上限、反向路径、出站间隔等高级参数默认折叠，常规接入只需一个地址和 token。
- 设置页平台切换：当确有多个平台同时生效时，设置页顶部提供平台切换标签（单个平台时面板标题已说明平台，不再显示该区块）；切换后即可查看该平台的配置并退出该平台账号。

## 🎨 体验

- 登录页布局：卡片改为填满视口高度并固定，表单区在内部滚动，切换 QQBot / OneBot 时卡片、立绘与底部控制条位置保持不动，页面也不会出现整体滚动条；平台表单在宽屏分两列排布，OneBot 的协议版本与地址字段可并排显示，可见内容明显增加。
- OneBot 表单样式统一：协议版本、连接模式沿用全局控件样式；快捷操作用「连接地址」标题右侧的动作按钮；测试与探测结果显示为一行状态（带状态色圆点），深色主题配色同步修正。
- 设置页状态卡片：OneBot 面板用卡片显示在线/离线、连接模式与收发计数，与仪表盘平台账号卡片同一套视觉。

## ♻️ 兼容性

- 旧的 OneBot 配置无需修改：保存时会自动补齐 `ws://` / `http://` 前缀并去除多余斜杠。
- 仍然只支持单一平台启用（QQBot 与 OneBot 二选一），本次未改变该限制。
- 协议端未开启 `access_token` 时行为不变；开启后需在 ISkyPro 侧填写完全相同的值。
