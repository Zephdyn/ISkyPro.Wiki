# 2.1.0

发布日期：2026-11-13

本次为稳定性版本，集中改善 ISky v1 插件的载入诊断与超时处理。本版本同时包含 2.1.0-preview.3 的 OneBot 连接诊断、Token 鉴权与反向接入改进（详见 [2.1.0-preview.3](/changelog/v2-1-0-preview-3)）。本版本不包含 Plugin SDK 接口变更，现有插件无需重新编译。

## ✨ 新功能

- 插件：ISky v1 插件的载入改用独立时限（默认 30 秒），不再与 5 秒的消息分发超时共用。首次启动被安全软件扫描、磁盘较慢，或插件初始化内部需要联网时，不再因为时限过短而失败。
- 插件：载入失败会给出可读原因，标明已经到达的阶段（未连接 / 未读取插件信息 / 未完成初始化），并附带宿主进程号与宿主日志路径；插件详情同样展示该原因。
- 插件：`isky.exe` 的输出写入 `data/logs/pluginhost/`，以 Windows 服务方式运行（没有控制台）时也能事后排查。每个插件保留最近 5 个日志文件，单个文件最大 8 MB。
- 设置页：「运行时」新增「载入超时 ms」，默认 30000，可直接在 WebUI 调整。

## ♻️ 兼容性

- 载入超时后宿主会被终止，并按崩溃策略延迟重启或停用，不再一直停留在“启动中”。
- 载入失败不再只显示 `Plugin ... is not initialized.`，排障时按错误中的阶段与宿主日志定位；排查方法见[插件故障排查](/plugins/troubleshooting)。
- 本版本无 Plugin SDK 接口变更；SDK 版本号随主程序同步为 `2.1.0`。
