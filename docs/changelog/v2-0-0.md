# 2.0.0

发布日期：2026-07-25

## Plugin SDK v2

- C#、Python、Node.js 和 Go SDK 进入稳定支持，统一使用有界事件队列、独立协议读取循环、request ID 多路复用、有限超时和 graceful shutdown。
- SDK 唯一源码、公共 Contracts、QQBot API catalog、生成器和四语言样例迁入公开 Wiki 仓库。
- catalog 可一次生成四语言方法、权限、稳定级别和模型元数据；`--check` 会阻止生成文件或版本漂移。
- Go 目录统一为 `sdk/go/iskypro`，公开 module path 为 `github.com/Zephdyn/ISkyPro.Wiki/sdk/go/iskypro/v2`。
- C# SDK 使用静态 `manifest.json` 作为唯一插件清单，并提供 NuGet 包与可运行 stdio 样例。
- SDK 发布包会在生成后解压，并真实构建或检查每种语言的 SDK 与样例。

## 兼容性

- C# 插件不再实现重复的 `Manifest` 属性；Node.js 生成方法统一返回 Promise。
- Python、Node.js 和 Go 不再公开可绕过 runtime reader loop 的低级直连 context 构造方式。
- 旧 DLL 插件继续使用 Windows/x86 隔离宿主；Linux 包只支持现代插件。

完整用户变更以 2.0.0 Release 和主程序内置更新日志为准。
