# 更新日志

本目录记录面向 ISkyPro 用户和插件开发者的公开版本更新说明。自 2.0.0 起，更新日志应保持简洁、风格一致，优先说明可感知改动、升级影响和插件开发变化，不展开主程序内部实现细节。

发布时同时维护两处公开信息：

- GitHub Release body：提供给 WebUI 更新检测弹窗或更新面板快速预览。
- Wiki changelog 页面：作为完整的公开版本说明和升级参考。
