# 更新日志

本目录记录面向 ISkyPro 用户和插件开发者的主程序公开版本更新说明。自 2.0.0 起，更新日志应保持简洁、风格一致，优先说明可感知改动、升级影响，不展开主程序内部实现细节。面向插件开发者的 SDK 变更（接口、协议、catalog、打包与迁移）请查看 [SDK 更新日志](/changelog/sdk/)，主程序日志仅在版本底部给出入口。

发布时同时维护两处公开信息：

- GitHub Release body：提供给 WebUI 更新检测弹窗或更新面板快速预览。
- Wiki changelog 页面：作为完整的公开版本说明和升级参考。
