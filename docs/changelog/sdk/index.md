# SDK 更新日志

本目录记录 Plugin SDK v2 面向插件开发者的版本说明，覆盖 C#、Python、Node.js 和 Go 四种官方 SDK 的接口变更、协议演进、catalog 方法、打包方式与迁移指引。主程序（框架）本身的变更见 [主程序更新日志](/changelog/)。

SDK 版本号与主程序保持一致，按语言发布为 `SDK-V2-<Language>-<version>.zip`（见 [SDK 下载](/plugins/downloads)）；同一版本号下两份日志对应同一次发布。
