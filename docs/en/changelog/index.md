# Changelog

This directory contains public release notes for the ISkyPro main application, for users and plugin developers. Starting with 2.0.0, entries should stay concise and consistent, lead with observable changes, and highlight upgrade impact without expanding into application internals. Developer-facing SDK changes (APIs, protocol, catalog, packaging, migration) live in the [SDK changelog](/en/changelog/sdk/); main-application entries only link to it at the bottom.

Release publishing should maintain two public sources:

- GitHub Release body: a quick preview for WebUI update prompts or update panels.
- Wiki changelog pages: the complete public release and upgrade reference.
