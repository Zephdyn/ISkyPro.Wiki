# SDK Changelog

This directory contains version notes for the Plugin SDK v2 aimed at plugin developers, covering API changes, protocol evolution, catalog methods, packaging, and migration guidance for the four official SDKs: C#, Python, Node.js, and Go. Changes to the main application (framework) itself are in the [main changelog](/en/changelog/).

SDK versions match the main application version and are published per language as `SDK-V2-<Language>-<version>.zip` (see [SDK Downloads](/en/plugins/downloads)); the two logs with the same version number describe the same release.
