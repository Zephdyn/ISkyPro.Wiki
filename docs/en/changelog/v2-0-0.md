# 2.0.0

Release date: 2026-07-25

## Plugin SDK v2

- C#, Python, Node.js, and Go SDKs are now stable, with bounded event queues, dedicated protocol reader loops, request-ID multiplexing, finite timeouts, and graceful shutdown.
- The canonical SDK source, public contracts, QQBot API catalog, generator, and four language samples moved to the public Wiki repository.
- One catalog generates method surfaces, permissions, stability levels, and model metadata for all languages; `--check` rejects generated-file or version drift.
- The Go directory is now `sdk/go/iskypro`, with public module path `github.com/Zephdyn/ISkyPro.Wiki/sdk/go/iskypro/v2`.
- The C# SDK uses a static `manifest.json` as the only plugin manifest and ships NuGet packages plus a runnable stdio sample.
- Every SDK release archive is extracted and its SDK and sample are actually built or syntax-checked before publication.

## Compatibility

- C# plugins no longer implement a duplicate `Manifest` property; generated Node.js methods consistently return Promises.
- Python, Node.js, and Go no longer expose low-level context constructors that bypass the runtime reader loop.
- Legacy DLL plugins remain on the isolated Windows/x86 host; Linux packages support modern plugins only.

See the 2.0.0 Release and the application changelog for the complete user-facing change list.
